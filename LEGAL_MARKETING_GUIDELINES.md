## ❌ PROHIBITED CLAIMS (Do Not Use)

### False Metrics
- ❌ "Used by X teams/companies" (unless true)
- ❌ "X% faster than competitors" (without data)
- ❌ Specific response times (without measurement)
- ❌ Uptime guarantees (without SLA)

### Compliance/Security
- ❌ "SOC 2 Certified/Ready" (not audited)
- ❌ "HIPAA Compliant" (not verified)
- ❌ "Bank-level security" (vague and unverifiable)
- ❌ "100% secure" (impossible claim)

### Technology
- ❌ "GPT-5 Powered" (doesn't exist)
- ❌ "Exclusive AI technology" (unless patented)
- ❌ "Only platform with..." (requires proof)
- ❌ "Patent-pending" (unless filed)

### Comparisons
- ❌ "Better than [Competitor]" (without evidence)
- ❌ "The Tesla/Apple/Uber of..." (trademark risk)
- ❌ "Kills/Destroys/Replaces [Product]" (disparagement)

## ⚠️ USE WITH CAUTION

### Conditional Claims (Add Disclaimers)
- "Up to X% improvement" (with footnote)
- "Can reduce project time" (results may vary)
- "Potential cost savings" (not guaranteed)
- "Early access pricing" (limited time)

### Beta/Preview Status
- Always include "Beta" or "Preview" prominently
- Add "Features subject to change"
- Include "Not all features available"

## 📝 REQUIRED DISCLAIMERS

```
© 2024 ProtoThrive. All rights reserved.

```

```
"Individual results may vary. This testimonial reflects one user's experience."
```

```
*Performance based on internal testing. Your results may differ.
```

### AI Features
```
AI capabilities depend on usage limits and available credits.
Accuracy not guaranteed. Human review recommended.
```

## 📊 METRICS TRACKING

Track these for future marketing claims:
1. Average response time (for speed claims)
2. Number of active users (for social proof)
3. Customer satisfaction scores (for testimonials)
4. Uptime percentage (for reliability claims)
5. Feature adoption rates (for effectiveness)
6. Cost savings data (for ROI claims)

## ⚖️ LEGAL REVIEW CHECKLIST

Before publishing any marketing material:

- [ ] All claims are truthful and substantiated
- [ ] Beta/preview status is clearly indicated
- [ ] Performance claims include qualifiers
- [ ] No competitor disparagement
- [ ] No trademark infringement
- [ ] Testimonials are real and permitted
- [ ] Disclaimers are included where needed
- [ ] Pricing is clearly marked as "subject to change"
- [ ] Terms of Service link is accessible
- [ ] Privacy Policy link is accessible

## 🚀 PHASED CLAIM EVOLUTION

### Phase 1: Pre-Launch (Current)
- Focus on vision and features
- Use "Coming Soon" and "Beta"
- Build waitlist numbers

### Phase 2: Beta Launch
- Add real user counts
- Include actual testimonials
- Share measured performance data

### Phase 3: General Availability
- Update all claims with real metrics
- Remove beta disclaimers
- Add customer logos (with permission)
- Include case studies

## 📞 ESCALATION PROCESS

If unsure about a claim:
1. Check this guide first
2. Apply the "truthfulness test"
3. When in doubt, add qualifiers
4. Consult legal counsel for:
   - Comparative advertising
   - Performance guarantees
   - Compliance certifications
   - Customer references
